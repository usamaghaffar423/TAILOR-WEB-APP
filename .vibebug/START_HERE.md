# VibeBug project memory v2

Do not preload `memory/index.json`. Build a short query from the issue route, component, symptom, error text, and likely files, then run:

`vibebug memory context "<query>" --budget 1400 --json`

The bounded pack prefers verified project/module/decision knowledge, includes at most five entries and two episodes, and must be checked against current code and tests. Completion records a compact episode; durable knowledge is saved only with explicit evidence.
