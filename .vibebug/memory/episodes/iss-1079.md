# Tailoring bills print and preview 2px larger without moving anything else.

Root cause: Both tailoring bills use the shared .bill-print stylesheet whose base/row text was 14px on screen and 11px in the thermal print block, with no larger variant for the two bills the shop reads most — and no way to enlarge them without also changing the POS receipts that share the stylesheet.

Fix/outcome: Added a .bill-print--tailoring modifier that lifts every text size by 2px (rows 14->16 screen, 11->13 print; sections 12->14 / 10->12; totals 16->18 / 13->15; footer, note, item detail, shop meta and shop title likewise) and applied it to the customer and karigar bill roots. Padding, margins, gaps and the flex label/value columns were untouched, POS receipts keep their original sizes, and the print pop-up picks the sizes up because the same CSS is inlined there.

Changed: frontend/src/billPrint.css, frontend/src/components/orders/CustomerBillModal.tsx, frontend/src/components/orders/KarigarBillModal.tsx

Verified: npm run build, npm run lint, deployed billPrint css contains all 20 bill-print--tailoring rules and the deployed bill chunk carries the class on both bills
